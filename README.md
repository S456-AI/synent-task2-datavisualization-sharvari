# Iris Dataset – Data Visualization
## Problem Statement
Raw datasets can contain patterns and relationships that are difficult to understand from tables alone. The objective of this project is to visualize the Iris dataset and compare its features using different types of graphs.

## Dataset Details
The Iris dataset contains measurements of different Iris flower species.
The main features are:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

The three species are:
- Setosa
- Versicolor
- Virginica

## Approach
The Iris dataset was loaded using Python and visualized using Matplotlib and Seaborn.
The following visualizations were created:
1. Bar Chart
   - Compared the average petal length of different Iris species.

2. Histogram
   - Showed the distribution of sepal length.

3. Scatter Plot
   - Compared sepal length and petal length to identify relationships between the features.

4. Feature Comparison
   - Compared the average values of sepal length, sepal width, petal length, and petal width across species.

## Results
The visualizations showed noticeable differences between the Iris species.
Petal-related measurements provide useful differences between species, while the scatter plot helps visualize the relationship between sepal length and petal length.
The graphs make it easier to understand patterns that are difficult to identify from raw tabular data.
